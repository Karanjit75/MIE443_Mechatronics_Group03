Contest 2 Terminator Commands

**Before testing, make sure the SO-ARM101 is connected: 
The wrist camera cable should be connected to the TurtleBot 4. 
The USB-C to USB-A cable should be connected from the arm controller board to the TurtleBot 4. 
The battery should be connected to the arm controller board

To restart Rasberry Pi:
ssh into turtlebot
sudo systemctl restart turtlebot4.service

Build Package:
cd ~/ros2_ws
colcon build
source install/setup.bash

AMCL Localization (new terminal):
ros2 launch turtlebot4_navigation localization.launch.py map:=<map_path>/<map_name>.yaml

Do cd ~/ros2_ws → ros2 launch turtlebot4_navigation localization.launch.py map:=src/mie443_contest2/maps/Contest2MapPractice.yaml (1 command together)

Nav2 (new terminal):
ros2 launch turtlebot4_navigation nav2.launch.py

RViz2 (new terminal):
ros2 launch turtlebot4_viz view_navigation.launch.py 

OAK-D Lite Camera Image Capture Server (new terminal):
ssh ubuntu@100.69.127.143
ros2 run mie443_contest2 image_capture_server
(OAK-D camera bringup: ros2 run rqt_image_view rqt_image_view)

YOLO Detector (new terminal):
cd out of ros2_ws folder

ros2 run mie443_contest2 yolo_detector.py
